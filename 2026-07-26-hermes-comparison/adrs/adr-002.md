# ADR-002: Resume falls back to event-log replay, not `session/new`

## Status

Accepted

## Date

2026-07-04

## Context

AGH delegates context restoration to the ACP subprocess via `session/load`
(`internal/acp/client.go:433-508`) and, when the agent doesn't support load or the load fails,
falls straight to `session/new` (`internal/session/manager_lifecycle.go:79-103`) — without ever
replaying the transcript AGH itself persists in `events.db`. Any ACP agent lacking durable context
silently loses the conversation on resume (defect D4, `analysis/summary.md`; slice 03 flagship,
`analysis/03_analysis_sessions-lifecycle.md` §5.1). Hermes cannot hit this class of bug because it
owns the message rows and always replays them; AGH owns an equivalent transcript and doesn't use
it. AGH's `internal/transcript` already assembles canonical replay messages from persisted events.

## Decision

1. In the resume path (`internal/session/manager_lifecycle.go` + `internal/acp/client.go`
   negotiation), when `session/load` is unsupported or `IsLoadSessionResourceMissing` fires,
   replay the persisted `events.db` transcript into the fresh subprocess (synthetic prime prompt or
   history block assembled by `internal/transcript`) instead of falling through to a bare
   `session/new`.
2. Emit a transcript marker ("context rebuilt from log") so UI/CLI truthfully show degraded-resume.
3. Replay is session-scoped and MUST NOT cross workspaces; apply a no-LLM prune pass
   (ADR-003 item 4) to keep the replay compact. **`archived` seam (peer-review round 1, B-004):**
   replay reads only `archived=0` events and injects the durable checkpoint-summary artifact
   (ADR-003 item 2) in place of archived spans — never the raw archived rows (no re-inflation of
   compacted context) and never a bare gap (no silent loss). Composition order is fixed: the
   archived filter applies first, then the prune pass.
4. Per SD-001, the resume path change must be re-evaluated against the activity supervisor when
   specced (it touches `internal/session/manager_*.go` and `internal/acp/client.go`).
