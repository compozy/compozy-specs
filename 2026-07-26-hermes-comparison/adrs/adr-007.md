# ADR-007: Automation suggestions without blueprints — loop templates are the canonical parameterized-template system

## Status

Accepted

## Date

2026-07-04

## Context

Slice 06 found AGH's automation *engine* already rivals Hermes (SQLite durable cursor, CAS claim,
full agent CRUD) but the *authoring/UX* layer above it is absent: Hermes ships 14 parameterized
blueprints (typed slots + form schema → job, `.resources/hermes/cron/blueprint_catalog.py:61-661`)
and a consent-first proactive suggestion store (sources `catalog|blueprint|usage|integration`,
dedup-latched dismissals, pending cap 5, `.resources/hermes/cron/suggestions.py`). `grep
blueprint|suggestion` over AGH = 0 hits.

However, the in-flight Loops spec (`.compozy/tasks/loops/_techspec.md`) already delivers a typed
template system: loop definitions with typed input schemas + form rendering (run-form screen,
editor renders from per-kind schemas), built-in templates embedded in the binary, and automations
gaining a discriminated target (`agent` | `loop`) so triggers/jobs/schedules become loop start
bindings; a shared template catalog is explicitly deferred evolution there. Building a second
typed-slot + form-schema system for plain jobs would create parallel template machinery — the
fragmentation the two-touch rule exists to prevent. User decision (2026-07-04): skip blueprints;
suggestions cover the authoring gap.

## Decision

1. **No Blueprint resource.** Loop templates are THE canonical parameterized-template system.
   Revisit only if real usage shows plain-job authoring needs typed slots (new ADR required).
2. **Suggestion store, consent-first:** sources `catalog|usage|integration` (no `blueprint`
   source), dedup-latched dismissals, pending cap (default 5), accept → create. A suggestion
   payload carries a prefilled plain `Job` spec (prompt + schedule — no slot machinery), and only
   that. **Loop-template variant deferred (peer-review round 1, N-001):** the loop-template
   suggestion payload is NOT built in this program — shipping it feature-gated would be inert
   scaffolding without a production caller; it lands with the Loops program as a hard cut when
   loop templates exist.
3. **Surfaces:** `agh__automation_suggestions_{list,accept,dismiss}` native tools, CLI/HTTP/UDS
   parity, a web card, and a 3–5-entry starter catalog seeded per new workspace
   (workspace-scoped; `Scope`+`WorkspaceID` already exist on automation rows).
4. **Engine correctness fixes ride the same program** (not blueprint-dependent): wire the dead
   `MisfireGraceSeconds` field, add `run_once_on_catchup` catch-up policy (+ DB CHECK migration at
   `internal/store/globaldb/global_db.go:2586`), add a self-overlap guard, and a lifetime
   `RunLimit` distinct from the rolling `FireLimit` (`internal/automation/model/types.go:164`).
5. **Non-goals:** JSON-file store, file-lock/TTL claims, `TERMINAL_CWD` serialization, per-job
   model/provider overrides (exfil surface), external scale-to-zero cron providers.
