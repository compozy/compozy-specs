# ADR-006: Cost estimation with provenance precedence; account-usage surface gated on token-reachability verification

## Status

Accepted

## Date

2026-07-04

## Context

AGH already captures full ACP `TokenUsage` (input/output/cache-read/cache-write/thought/context),
aggregates it to per-session `store.TokenStats{TotalCost}` (`internal/store/types.go:581-606`,
`internal/observe/observer.go:759`), and carries `Cost{Input,Output}PerMillion` in the merged model
catalog (`internal/modelcatalog/types.go`) — but it never multiplies tokens × rates; `TotalCost` is
nil unless the agent volunteers it (slice 07 #1 gap). Hermes' `estimate_usage_cost` is exactly the
missing join. Hermes also prices cache/reasoning buckets, carries cost provenance, and reads
account-quota endpoints (Anthropic OAuth / Codex / OpenRouter usage APIs). Hermes' prepaid billing
(`billing_view.py`) and model-API `fallback_chain` are architecture-mismatched — AGH has no billing
relationship with providers and no in-process model client to hot-swap (slice 07 §5).

## Decision

1. **Cost-estimation service** (`internal/usage` or catalog-local `pricing.go`):
   `EstimateCost(provider, model, TokenUsage) → CostResult{Amount, Currency, Status, Source}`,
   rates from the merged catalog. Precedence is strict and non-summing:
   agent-reported `actual` > AGH `estimated` > `included` > `unknown`. Wire into
   `TokenStatsUpdate` and the task roll-up (`internal/task/live.go:556-586`) so `TotalCost`
   populates even when the agent is silent; surface through existing CLI/HTTP/extension payloads.
2. **Four-bucket + reasoning pricing:** nullable `CostCacheReadPerMillion`,
   `CostCacheWritePerMillion`, `CostReasoningPerMillion` across catalog rows, provider config
   (`internal/config/provider.go:164-165`), models.dev mapping, extension model source, contracts.
3. **Cost status + source on aggregates:** `CostStatus` (`actual|estimated|included|unknown`) and
   `CostSource` (`agent_reported|catalog_config|models_dev|builtin|none`) on
   `TokenStats`/`TokenStatsUpdate` — append-only migration on the global DB.
4. **`subscription_included` classification** driven off provider auth mode (never a hardcoded
   provider list): native subscription CLIs (Claude Code, Codex) report `included`, not a fake `$`.
5. **Account-usage surface is GATED:** before any implementation, verify whether native-CLI
   provider credentials can (and should, under L-015 auth-boundary constraints) reach provider
   usage endpoints. If yes: read-only `agh provider usage <provider>` + HTTP endpoint, fail-open,
   operator/global-scoped without leaking spend into workspace session lists. If no: the surface
   reports `included/unknown` truthfully and the fetcher is dropped.
6. **Non-goals:** prepaid billing/monthly-cap/auto-reload; model-API fallback chains (session-level
   ACP agent failover is a separate future spec anchored on `internal/providers/classify.go`);
   transport/api_mode quirks (owned by the subprocess).
