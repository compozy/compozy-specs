# ADR-008: macOS app artifacts are per-architecture, not universal

## Status

Accepted

## Date

2026-08-15

## Context

The Tauri app ships one universal macOS artifact (`CompozyOS_<v>_universal.*` — both architectures in one bundle, roughly double the download). Both Electron reference repos (`.resources/synara`, `.resources/t3code`) converged on per-arch builds (arm64 + x64 dmg/zip) with per-arch update manifests merged at release time, and disable differential downloads only for the cross-arch (Intel-build-on-Apple-Silicon) case. The runtime archives are already per-arch (`compozy_darwin_{arm64,x86_64}.tar.gz`).

## Decision

macOS app artifacts build per architecture: arm64 and x64 dmg + zip, with the per-arch update manifests merged into the release's channel manifest. Linux stays x64 (AppImage + deb). The artifact inventory assertion is updated to the new exact set.

## Alternatives Considered

### Alternative 1: Universal binary (today's shape)

- **Description**: One mac artifact containing both architectures.
- **Pros**: One download link; inventory unchanged in spirit.
- **Cons**: ~2× download and disk for every user; Electron universal builds have their own pitfalls; differential updates work worse; both reference implementations moved away from it.
- **Why rejected**: Per-arch is smaller for every user and the established Electron pattern (user decision T2, 2026-08-15).

## Consequences

### Positive

- Roughly half the download/install size per mac user; better differential updates.
- CI matrix mirrors the reference repos' proven shape (two mac builders + manifest merge).

### Negative

- Two mac build jobs instead of one; the install page needs per-arch links or detection.
- Cross-arch edge (x64 build running under Rosetta) needs the reference repos' guard: disable differential download and allow the updater to cross to arm64.

### Risks

- Manifest-merge mistakes serving the wrong arch — mitigated by the merge-script pattern from the references plus the release smoke installing on both arches.

## Implementation Notes

Inventory moves from `CompozyOS_<v>_universal.*` to per-arch names; `internal/desktoprelease/inventory.go`'s exact-set assertion is rewritten for the new set in the same change.
