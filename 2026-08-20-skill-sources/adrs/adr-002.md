# ADR-002: v1 preset curation — `agents` on by default, `claude` available, everything else deferred

## Status

Accepted

## Date

2026-08-20

## Context

vercel-labs/skills maps 77 agent tools to skill folders; offering all of them as presets would bloat the UI and the support surface. CompozyOS spawns Claude Code, OpenClaw, and Hermes as providers, and the `.agents/skills` universal convention is read natively by 19+ tools. The preset table is daemon-owned Go code, so adding a preset later is a one-row change.

## Decision

The v1 preset table contains exactly three entries:

| slug | workspace root | global root | state |
|---|---|---|---|
| `compozy` | `<ws>/.compozy/skills` | `$COMPOZY_HOME/skills` | always on, implicit (ADR-003) |
| `agents` | `<ws>/.agents/skills` | `~/.agents/skills` | **default ON** |
| `claude` | `<ws>/.claude/skills` | `~/.claude/skills` | available, default off |

`codex`, `hermes`, `openclaw` (global-only), `cursor`, and `opencode` are deferred — each is a one-row additive change when demanded.

## Alternatives Considered

### Alternative 1: Provider-first table (agents + claude + codex + hermes + openclaw)

- **Description**: Include every provider CompozyOS spawns plus codex.
- **Pros**: Covers native skill homes of all three providers at launch.
- **Cons**: Hermes/OpenClaw skills already reach the catalog via `agents` (both read `.agents/skills` natively, so users following the universal convention need nothing else); more rows to test, document, and QA.
- **Why rejected**: Owner trimmed to the minimum that covers the stated need; additions are cheap later.

### Alternative 2: Full ecosystem table (8+ presets)

- **Description**: Ship cursor/opencode/codex/hermes/openclaw rows immediately.
- **Pros**: Maximum out-of-box interop.
- **Cons**: Most rows are global-only niches for a daemon host; every row multiplies settings QA scenarios.
- **Why rejected**: No demonstrated demand; violates scope minimalism.

## Consequences

### Positive

- Small, testable table; UI shows three rows, not a wall of toggles.
- `agents` default-ON delivers the headline requirement (load `~/.agents/skills` + `<ws>/.agents/skills` by default).

### Negative

- Users of deferred tools must use `custom_sources` until their preset lands.

### Risks

- Preset requests arrive early — mitigated: additive one-row change, no schema/contract impact.

## Implementation Notes

Table lives in one Go file (à la vercel-labs `src/agents.ts`): `{slug, label, workspaceRelPath, globalPath, nativeReaders}` (nativeReaders per ADR-009). OpenClaw's bare `<ws>/skills` project dir is permanently excluded (ADR-014).
