# ADR-006: Fail-closed exposure with agent-operable self-audit

## Status

Accepted

## Date

2026-08-06

## Context

Post-incident, the agent-runtime market converged on fail-closed exposure: Hermes refuses to start when a non-loopback bind lacks an auth provider (and neutered its `--insecure` flag after a June 2026 exploitation campaign); OpenClaw hard-errors on a network bind without declared auth and ships a `security audit` command with `--fix`. The common root cause across incidents was never a bad default — it was the ability to reach an unsafe state at all, plus users' inability to see their own posture.

Compozy today has the opposite failure shape (non-loopback bind = dead API), so this feature is where exposure semantics get defined for good. Compozy's agent-manageability posture also requires that agents — not just humans — can inspect and reason about exposure state.

## Decision

- **Fail-closed is absolute.** The daemon refuses any configuration or runtime transition that would make a surface reachable beyond the local machine without the authentication model active. The refusal names the exact cause and fix. No override flag exists, and none will be accepted for compatibility.
- **Exposure state is always discoverable**: current mode, every active endpoint, which surfaces are reachable at each, device inventory, and provider health — via UI and structured command output.
- **A security self-audit verb ships with the feature**: it reports exposure posture, auth state, public surfaces, device inventory, and findings with severity and concrete remediation, in both human-readable and machine-readable forms, so agents can audit and repair their own daemon's posture.
- **Secrets never cross surfaces**: pairing artifacts, provider credentials, and webhook secrets are redacted from logs, status output, diagnostics, and events; only fingerprint/hash forms may appear (consistent with the existing claim-token redaction invariant).
- **Teardown is deliberate**: disabling exposure (or shutting down) deterministically removes public reachability; a restart never silently re-exposes a surface the operator turned off.

## Alternatives Considered

### Alternative 1: Warn-but-allow

- **Description**: Permit unauthenticated exposure with loud warnings.
- **Pros**: Maximum operator freedom; fewer support cases for exotic setups (e.g., an external identity proxy in front).
- **Cons**: Every reference that allowed it produced an incident class; scanners find exposed daemons within minutes; warnings are ignored at scale.
- **Why rejected**: An agent daemon holds credentials and shell access; an unauthenticated remote daemon is equivalent to remote code execution. Operators with their own identity proxy still terminate at a loopback daemon, which remains supported.

### Alternative 2: Fail-closed without a self-audit verb

- **Description**: Enforce safety at startup only.
- **Pros**: Less to build.
- **Cons**: Posture drifts after startup (provider changes, surface toggles); agents cannot verify or repair exposure; humans get no continuous view.
- **Why rejected**: Discoverability is half the lesson from the incident record; SD-011 requires the agent path.

## Consequences

### Positive

- The unsafe state is unrepresentable rather than discouraged.
- Agents can be tasked with "check and fix my exposure" end to end.
- Support burden shifts from incident response to actionable refusal messages.

### Negative

- Legitimate edge setups must conform (external proxies still front a loopback daemon; no unauthenticated network bind, ever).
- Refusal diagnostics become a maintained product surface with quality expectations.

### Risks

- Overly strict rules block a real workflow we did not foresee; mitigated by the audit's remediation guidance and by treating each refusal message as a designed product surface with a documented path forward.

## Implementation Notes

Enforcement points, audit check catalog, and redaction mechanics belong to the TechSpec. The existing security invariants (claim-token redaction, path hardening) extend to the new surfaces rather than being re-invented.
