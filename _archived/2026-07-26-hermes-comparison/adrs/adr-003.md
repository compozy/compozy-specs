# ADR-003: Wire the inert compaction scaffolding; durable checkpoint summaries; never rewrite the subprocess window

## Status

Accepted

## Date

2026-07-04

## Context

Two independent slices converged (SD-009 pattern): AGH ships compaction *contract* with no
*consumer*. `runContextCompaction` + `HookContextPreCompact`/`PostCompact` have no production
caller — only tests invoke them (`internal/session/manager_hooks.go:492`) — and
`contract.MemoryProvider.OnPreCompress` mirrors Hermes' provider ABC
(`.resources/hermes/agent/memory_provider.py:220`) while being equally inert
(`internal/memory/contract/types.go`). Long sessions therefore depend entirely on the subprocess
self-compacting; when it doesn't, the run dies at the provider with a context-length error AGH can
only classify post-hoc (defect D3). The greenfield rule allows exactly two exits: wire it or
delete it ("no scaffolding without a production caller").

Hermes' compressor carries guards worth copying — per-turn attempt cap
(`.resources/hermes/agent/conversation_loop.py:488`), failure cooldown
(`.resources/hermes/hermes_state.py:1824`), non-destructive archive, iterative checkpoint summary
(`.resources/hermes/agent/context_compressor.py:1642-2771`) — and mechanics that must be rejected:
live rewriting of the context window, session-rotation-on-compaction, compression locks, char-cap
accounting (slice 01 §5). The architectural line: the ACP subprocess owns its window; AGH must
never silently rewrite it.

## Decision

1. **Wire, don't delete.** Add a compaction driver keyed off context-window pressure (ACP usage
   updates) routing through the existing `HookContextPreCompact`/`PostCompact`, with Hermes'
   guards: attempt cap, failure cooldown, non-destructive event archiving (new `archived` flag on
   events — append-only migration, `eng-schema-migration`). Config under `[session.compaction]`.
2. **Durable cross-session checkpoint summary as a memory artifact** (not live compaction): an
   iteratively *updated* (never regenerated) checkpoint-summary record produced at AGH-controlled
   boundaries — **the compaction boundary plus session end / dream** — injected as a prompt block;
   adopt Hermes' heading schema in `dream`'s consolidation prompt. Append/update-only, revertible
   via the existing decision WAL, never overwrites raw transcript or Markdown source-of-truth.
   **Compaction-boundary ordering (peer-review round 3, B-301):** the pre-compact extraction
   updates the summary to cover the span being archived BEFORE those events are flagged
   `archived`, so a crash in any window (including before a clean session end) leaves either the
   raw events or a covering summary — never neither; without this, decision 1's archiving composed
   with ADR-002's `archived=0` replay filter would silently lose the archived span on a
   crash-then-resume, reintroducing D4 through the compaction path.
3. **Rejects (non-goals):** rewriting the live subprocess window, session rotation on compaction,
   compression-lock columns, char caps, SaaS memory backends in core, vectors in core FTS
   (semantic recall stays extension-only behind `internal/extension/memory_provider_registry.go`).
4. **Supporting memory hardening rides along:** no-LLM transcript prune (1-line tool-result
   summaries + dedup) in `internal/transcript` consumed by extractor/replay; prefix-cache
   byte-stability audit of injected prompt segments; dream anti-thrash/ineffective-run backoff;
   atomic batch semantics for `agh__memory_*` (slice 01 R1/R2/R4/R5).
